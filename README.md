# Grand Theft Developer

A GTA VI-style developer portfolio. Fan-made, not affiliated with Rockstar Games.

**Demo:** https://uiblox.github.io/gta-fan-made-landing-page/

React + Vite, Tailwind CSS, GSAP. See `AGENTS.md` for the build method and project status, and `CONTENT.md` for the page copy.

```
npm install
npm run dev
```
